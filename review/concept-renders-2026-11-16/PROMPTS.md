# Generation prompts

Generated with the built-in image generation tool, one image per scene. These are concept proposals, not rendered screenshots.

## Shared prompt

Use case: stylized-concept. Create one polished 3D diorama render for the Open Philosophy interactive project, suitable as an aspirational scene-model review image. Single distinct scene only, not a collage; a complete small circular dark sage platform against a warm ivory studio background, three-quarter isometric camera, coherent tabletop scale, detailed crafted geometry, tasteful matte stone, wood and muted teal/ochre/terracotta materials, soft directional light and readable shapes. Visually improve the existing schematic model while retaining the concept and composition. No UI, no labels, no typography, no logos or watermarks, no photoreal historical reconstruction claims.
